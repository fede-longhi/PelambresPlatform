# Respuestas de DM (copiar / adaptar)

### Primera respuesta

```
Hola! Gracias por escribir 🙌

El porta equipo es custom:
1) color (negro / verde / violeta u otro que tengamos)
2) cantidad de agujeros (según cuántos draws/cintas querés colgar)

Contame eso y te paso opciones + precio y plazo.
```

### Si preguntan precio sin datos

```
Dale — para pasarte número justo necesito:
· color
· aprox. cuántos quickdraws / cintas querés colgar

Con eso te armo la propuesta.
```

### Si preguntan si es para asegurar / anclar

```
Buena pregunta: no es EPP.
Es solo para organizar el equipo (en casa / placard / transporte).
No está pensado para anclar ni para cargar peso de seguridad.
```

### Si eligen y confirman

```
Perfecto. Queda:
· Color: [X]
· Agujeros: [N]

Te confirmo precio $[ ] y plazo aprox. [ ] días.
¿Lo cerramos?
```

### Si piden foto de otro color / tamaño

```
Te mando referencia de ese color/config.
También podemos ajustar agujeros a lo que necesites.
```
